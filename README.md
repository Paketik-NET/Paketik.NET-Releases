## Это бета

Приложение раздаётся узкому кругу и ещё меняется. Работать работает, но
местами шероховато, и обновления приходят часто. Не работает или ведёт себя
странно — [напишите в поддержку](https://t.me/Paketik_net_bot).

## Как поставить

1. Скачайте файл.
2. Откройте его. Телефон спросит разрешение ставить приложения из этого
   источника — так он спрашивает про всё, что пришло не из Google Play.
   Разрешите, это делается один раз.
3. Войдите через Telegram или по почте. 

Новая версия ставится поверх старой тем же файлом — данные и вход
сохраняются, удалять предыдущую не нужно.

## Что нужно телефону

| | |
|---|---|
| Android | 7.0 и новее |
| Процессор | 64-битный — это все телефоны, кроме совсем старых |
| Место | около 60 МБ |
